# CodeAlpha Python Programming Internship - Tasks

This repository contains my tasks for the CodeAlpha Python Programming internship (October batch).

## Task 1: Hangman Game
Folder: `Task1_Hangman`

A text-based Hangman game played in the console.
- The computer picks a random word from a list of 5 words.
- The player guesses one letter at a time.
- The player can make 6 wrong guesses.
- The program checks for invalid input and repeated letters.

Run: `python3 hangman.py`

## Task 2: Stock Portfolio Tracker
Folder: `Task2_StockPortfolioTracker`

A program that calculates the total investment value of a stock portfolio.
- Stock prices are stored in a dictionary.
- The user enters stock names and quantities, and types `done` to finish.
- The program shows the total so far after each stock and the final total at the end.
- The result is saved in `portfolio.txt`.

Run: `python3 stock_tracker.py`

## Concepts used
Variables, strings, lists, dictionaries, loops, if-else, functions from the `random` module, input validation with try-except, and file handling.
